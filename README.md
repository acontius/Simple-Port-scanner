##  درباره پروژه
این پروژه یک ابزار اسکن پورت خط فرمان (CLI) است که با زبان **Python** توسعه یافته است. هدف اصلی این پروژه پیاده‌سازی مفاهیم آموزشی درس امنیت شبکه (فصل ۸: Reconnaissance & Scanning) است. این ابزار صرفاً برای **مقاصد آموزشی** طراحی شده و استفاده از آن روی شبکه‌هایی بدون اجازه کتبی ممنوع است.

##  تاریخچه فایل‌ها
| فاز | نام فایل | توضیحات |
|-----|----------|---------|
| فاز ۱ | `phase1.py` | راه‌اندازی اولیه، دریافت ورودی‌ها (Argparse) |
| فاز ۲ تا ۴ | `Port-Scanner.py` | توسعه قابلیت‌های اسکن، سرویس‌دهی و گزارش‌گیری |

##  ویژگی‌ها به تفکیک فاز

###  فاز ۱: زیرساخت و CLI
- دریافت آرگومان‌های خط فرمان (Target, Ports).
- اعتبارسنجی آدرس IP.
- طراحی ساختار ماژولار.
- **ارجاع به جزوه:** مفاهیم اولیه Reconnaissance.

###  فاز ۲: اسکنر TCP Connect
- پیاده‌سازی اسکن پورت با استفاده از `socket`.
- استفاده از متد `connect_ex` برای تشخیص پورت‌های باز.
- مدیریت خطا و Timeout.
- **ارجاع به جزوه:** اسلاید ۲۱ (TCP Connect Scanning & 3-Way Handshake).

###  فاز ۳: شناسایی سرویس و گزارش‌دهی
- شناسایی سرویس‌های رایج بر اساس شماره پورت.
- قابلیت Banner Grabbing (دریافت نسخه سرویس).
- ذخیره خروجی اسکن در فایل متنی.
- **ارجاع به جزوه:** اسلاید ۲۷ (Fingerprinting).

###  فاز ۴: کشف میزبان و تشخیص OS (نسخه نهایی)
- بررسی آنلاین بودن هدف قبل از اسکن (Ping Sweep).
- تشخیص حدسی سیستم عامل بر اساس پورت‌های باز.
- بهینه‌سازی سرعت با استفاده از Multi-Threading.
- بنر اخلاقی و امن ACONTIUS.
- **ارجاع به جزوه:** اسلاید ۱۸ (ICMP Method) و اسلاید ۲۸ (OS Detection).
